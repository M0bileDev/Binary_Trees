# Binary Trees 🌳

A Kotlin implementation of **Binary Tree** data structure with node construction and traversal algorithms.

> 📚 Built as a learning project following the **Data Structures & Algorithms in Kotlin** book by Kodeco (Ray Wenderlich).

---

## Features

- 🏗️ **Tree Construction** — build binary trees with left and right child nodes
- 🔄 **In-Order Traversal** — visit left subtree, node, then right subtree
- ⬇️ **Pre-Order Traversal** — visit node first, then left and right subtrees
- ⬆️ **Post-Order Traversal** — visit left and right subtrees, then the node

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/M0bileDev/Binary_Trees.git
   ```

2. Run the project:
   ```bash
   ./gradlew run
   ```

> **Note:** The default branch is `develop`.

## Purpose

This project was developed as a hands-on learning exercise to practice binary tree fundamentals in Kotlin, covering node-based tree construction and depth-first traversal strategies (in-order, pre-order, post-order).
